# asif.abbas

Portfolio of Muhammad Asif Abbas (Business Development, NaxTech). A single static page you move through like a sales deal, from Prospecting to Closed Won.

Plain HTML, CSS and JavaScript. No build step.

- `index.html` - the whole site
- `img/` - photos
- `Muhammad_Asif_Abbas_Resume.pdf` - résumé download

Run locally: `python -m http.server` in this folder, then open http://localhost:8000
Deploy: import this repo in Vercel with Framework Preset "Other" and no build command.
